# 실내 화재 대피 유도 시스템 (SIGNAL_SPEAK)

소속 및 팀원: 전자공학과 SIGNAL_SPEAK 팀 (최성용, 구민서, 이명은, 권은지)  
개발 환경: ESP32 DevKit, C/C++ (Arduino IDE), Jupyter Notebook  

---

## 1. 프로젝트 개요

### 1.1 개발 배경 및 필요성

- **기존 비상유도등의 시인성 한계**: 화재 발생 시 발생하는 유독 연기는 상부로 급격히 확산되어 벽면 상단에 고정된 기존 비상유도등을 가리게 됩니다. 이로 인해 요구조자의 시야 확보가 어려워져 탈출 골든타임을 놓치는 문제가 지속적으로 발생하고 있습니다.
- **정적 안내 시스템의 위험성**: 기존 유도등은 화재 발생 위치와 무관하게 항상 일정한 방향만 고정 지시하므로, 오히려 화재가 발생한 위험 구역으로 대피를 유도할 수 있는 치명적인 맹점이 존재합니다.
- **솔루션 제안 (SIGNAL_SPEAK)**: 화재를 실시간으로 감지하고 연기층 아래인 바닥 레벨에서 안전한 최단 탈출 경로를 시각적(동적 LED 파도 효과)·청각적(다중 주파수 부저)·텍스트(LCD 방 번호 표시)로 안내하는 스마트 대피 시스템을 설계 및 구현하였습니다.

### 1.2 프로젝트 최종 목표

- **ESP32 및 불꽃 센서 기반 화재 감지**: 다중 구역에 분산 설치된 화염 센서를 실시간 폴링하여 화재 발생 위치를 즉각 판별.
- **상황별 LCD 화재 위치 표출**: 평상시 안정 상태 및 화재 발생 시 발화 구역 방 번호를 I2C 1602 LCD 화면에 실시간 안내.
- **WS2812B LED 동적 경로 유도 및 부저 경보**: 화재 구역은 적색으로 진입 차단, 안전 탈출로 방향으로는 녹색 파도 애니메이션을 점등하고 순차 주파수 부저 경보 동시 발령.

## 2. 시스템 구조도 및 제어 알고리즘

### 2.1 시스템 구조도

전체 시스템은 센서 입력부 - ESP32 제어부 - 다중 출력부의 융합 구조로 설계되었으며, 저비용·단순 구성으로 높은 현장 확장성을 가집니다.

```text
[입력부: 다중 불꽃 센서] ──(Digital GPIO)──> [제어부: ESP32 DevKit] ──(FastLED)──> [출력부: WS2812B LED 스트립]
                                                                    ──(I2C Com.)─> [출력부: I2C LCD 1602]
                                                                    ──(PWM/Tone)─> [출력부: 피에조 부저]
```

### 2.2 메인 제어 알고리즘 및 동작 기준

| 동작 단계 | 시스템 제어 상태 | 상세 동작 내용 |
| :--- | :--- | :--- |
| **01. 평상시 (Safe Mode)** | 전 구역 안전 점등 | LCD에 `"System Stable / Safe State"` 출력, 전체 LED 녹색 상시 점등 유지 |
| **02. 화재 감지 (Fire Event)** | 센서 신호 수신 | 특정 구역 적외선 불꽃 센서로부터 화재 신호 감지 (소프트웨어 필터링 적용) |
| **03. 화재 위치 표출** | LCD 발화 위치 표시 | LCD 1열에 `"WARNING: FIRE!!"`, 2열에 `"Room 1 Evacuate"` 등 발화 방 번호 표시 |
| **04. 위험 구역 차단** | 적색 LED 차단 경고 | 화재 발생 구역 인접 LED 라인을 적색(Red)으로 즉시 점등하여 진입 차단 |
| **05. 동적 경로 유도** | 녹색/청색 파도 점등 | 안전 비상구 방향으로 LED가 순차 이동하는 파도 효과(Wave Animation) 점등 |
| **06. 청각 경보 발령** | 다중 주파수 경보 | 피에조 부저에서 서로 다른 주파수 톤을 순차 출력하여 청각 경보 인지도 극대화 |                   

## 3. 실시간 모니터링 시뮬레이션

```c
#include <Wire.h>
#include <LiquidCrystal_I2C.h>
#include <FastLED.h>

// 핀 및 시스템 파라미터 정의
#define LED_PIN       14
#define NUM_LEDS      60
#define FLAME_SENSOR  12
#define BUZZER_PIN    13

CRGB leds[NUM_LEDS];
LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  Serial.begin(115200);
  pinMode(FLAME_SENSOR, INPUT);
  pinMode(BUZZER_PIN, OUTPUT);
  
  FastLED.addLeds<WS2812B, LED_PIN, GRB>(leds, NUM_LEDS);
  lcd.init();
  lcd.backlight();
  
  showNormalStatus();
}

void loop() {
  // 실시간 센서 폴링 모니터링
  int fireDetected = digitalRead(FLAME_SENSOR);
  
  if (fireDetected == HIGH) { 
    triggerFireAlarm();
  } else {
    showNormalStatus();
  }
  delay(30); // 시뮬레이션 루프 주기 최적화
}

// 평상시: 안전 모니터링 상태
void showNormalStatus() {
  lcd.setCursor(0, 0);
  lcd.print("System Stable   ");
  lcd.setCursor(0, 1);
  lcd.print("Safe State      ");
  noTone(BUZZER_PIN);
  
  fill_solid(leds, NUM_LEDS, CRGB::Green); // 안전 구역 초록색 맵핑
  FastLED.show();
}

// 화재 발생 시: 동적 대피 유도 알고리즘 시뮬레이션
void triggerFireAlarm() {
  lcd.setCursor(0, 0);
  lcd.print("WARNING: FIRE!! ");
  lcd.setCursor(0, 1);
  lcd.print("Room 1 Evacuate "); // 화재 위치 정확히 전달
  
  tone(BUZZER_PIN, 1000); // 청각적 경고음 발령
  
  // LED 구간 매핑 및 파도 효과 연출 
  static uint8_t waveIndex = 0;
  waveIndex++;
  
  for (int i = 0; i < NUM_LEDS; i++) {
    if (i < 15) {
      leds[i] = CRGB::Red; // 위험 구간 빨간색 매핑
    } else {
      // 탈출 방향 안내 파란색 파도 효과 (흐름 제어)
      if ((i - 15) % 8 == (waveIndex % 8)) {
        leds[i] = CRGB::Blue;
      } else {
        leds[i] = CRGB::Black; 
      }
    }
  }
  FastLED.show();
  delay(100); // 파도 애니메이션 속도 제어
}
```

## 4. 세부 구현 내용 및 하드웨어 트러블슈팅

### 4.1 전원 공급 문제로 인한 MCU 손상 방지 및 전원 분배 재설계
- **문제**: 프로젝트 초기 5V 전원 어댑터 전류가 ESP32(내부 로직 3.3V) 인가단 전압 변동을 일으켜 MCU 기기 2대가 손상되는 문제 발생.
- **해결**: 외부 5V 전원을 LED 스트립에 직접 바이패스하고, ESP32의 Vin 레귤레이터 핀으로 안전하게 인가되도록 전원 분배 라인을 분리 및 재설계하여 해결함.

### 4.2 공통 접지(Common Ground) 결선을 통한 LED 신호 노이즈 해결
- **문제**: 테스트 중 LED 색상 데이터가 튀거나 제어되지 않는 노이즈 현상 발생.
- **원인**: ESP32와 외부 LED 전원 공급 장치 간의 신호 기준점이 불일치하는 공통 접지 미형성 문제.
- **해결**: 회로 상의 모든 GND 라인을 공통으로 결선(Common Ground)하여 신호 기준점을 일치시킴으로써 데이터 무결성 확보.

### 4.3 긴 대피로 인스턴스에서의 데이터 신호 감쇠 및 배선 최적화
- **문제**: 스트립 연장 시, 전반부 LED는 정상 작동하나 후반부 LED 라인의 데이터 왜곡 및 품질 저하 발견.
- **해결**: 신호선 배선 길이를 최소화하고 분기점 회로를 개선하는 구조적 배선 최적화를 통해 데이터 품질 확보.

### 4.4 외란광 노이즈로 인한 불꽃 센서 오작동 정밀 튜닝
- **문제**: 주변 태양광 및 실내 조명등의 적외선 파장 노이즈로 인해 화재가 없음에도 센서가 오작동함.
- **해결**: 불꽃 센서 모듈의 가변저항을 통한 하드웨어 감도 튜닝 및 소프트웨어 필터링을 통해 확실한 화재 불꽃 파장 대역에만 반응하도록 설정.

## 5. 나의 역할 및 문제 해결 과정

### 5.1 담당 역할: I2C LCD 출력 및 상황별 경보 시스템 구현
본 프로젝트에서 저는 **I2C 1602 LCD 출력 기능을 중심으로 화재 감지 정보 시각화와 경보 상태 표시**를 전담하여 시스템의 직관적인 사용자 인터페이스를 완성했습니다.

- **상황별 LCD 화면 상태 분기**: 평상시 안정 상태(`System Stable / Safe State`)와 화재 발생 시 경고 문구(`WARNING: FIRE!!`)의 실시간 전환 로직 구현.
- **화재 발생 방 번호 실시간 표출**: 다중 불꽃 센서 신호를 분석하여 발화가 일어난 구역(예: `Room 1 Evacuate`)을 LCD 화면에 명확하게 표시함으로써 대피자와 구조 인력이 발화 위치를 즉각 파악할 수 있도록 개발.
- **청각적 부저 경보 연동**: LCD 상태 갱신과 동시에 피에조 부저의 주파수 경보음을 동기화하여 시각·청각 복합 피드백 제공.
- **프로젝트 문서화 및 하드웨어 결선 조율**: 팀원들과의 회로 결선 및 펌웨어 통합 과정 조율 및 문서화 관리.

### 5.2 문제 해결 과정 (Troubleshooting)

**🛠️ 트러블슈팅: 다중 센서 폴링 시 LCD 깜빡임(Flicker) 현상 개선**
- **문제점**: 센서 폴링 루프마다 `lcd.clear()`를 반복 호출하면서 LCD 화면이 지속적으로 깜빡거려 가독성이 크게 저하됨.
- **해결 방법**: 직전 상태 플래그를 두어 상태가 변경되는 순간에만 화면을 갱신하도록 이벤트 기반 디스플레이 출력 로직으로 리팩토링하여 부드러운 텍스트 표출 구현.

## 7. 결과 분석 및 기대효과

### 7.1 프로젝트 최종 결과 분석
- **임베디드 소방 안전 시나리오 동작 검증**: 축소 구조물 모델 환경에서 화재 감지 ──> ESP32 신호 처리 ──> 동적 LED 파도 안내선 점등 ──> LCD/부저 다중 경보로 이어지는 연동 시나리오 동작에 100% 성공하였습니다.
- **바닥 매립형 LED 시인성 입증**: 연기가 가득 찬 모의 화재 환경에서도 상단 비상구 유도등 대비 월등한 가시성과 최단 탈출 경로 시인성을 확인하였습니다.

### 7.2 기대효과 및 향후 개선 과제
- **스마트 빌딩 소방 안전성 확보**: 저비용·단순 구성의 하드웨어 융합 시스템으로 실제 복잡한 복도나 다중이용시설에 도입 시 인명 피해를 획기적으로 줄일 수 있습니다.
- **향후 IoT 확장 계획**:
  1. **고도화 알고리즘 적용**: 대규모 복잡 건물 구조에 대응하기 위해 고정 경로 외에 그래프 기반 최단 경로 탐색 알고리즘(Dijkstra, A* 알고리즘)을 소프트웨어에 추가 반영 계획.
  2. **무선 중앙 모니터링 연동**: ESP32의 내장 Wi-Fi/BLE 통신 기능을 활성화하여, 화재 발생 시 건물 중앙 방재실 모니터링 시스템 및 요구조자 모바일 앱으로 대피 경로를 실시간 원격 전송하는 통합 IoT 인프라로 고도화 가능.
